# Открытый план изучения

Точки продолжения и сохранённые интересы по
[общему правилу практикума](specification.md#открытое-изучение-тем-и-выбор-следующей-задачи).
Перечни ниже открыты и не задают порядок или границу темы. Подробные
постановки появляются при выборе конкретной задачи; новые направления
нейросеть предлагает в разговоре. Уже отмеченные интересы можно выбирать,
откладывать и дополнять.

## Текущее состояние и точки продолжения

Базовые реализации списков, парных стеков, очередей и деков оформлены;
статус отдельных упражнений и расширений приведён в
[тестовой лаборатории](testing.md). Завершение этих упражнений не закрывает
соответствующие темы для новых задач и применений.

| Направление | Текущее состояние | Ближайшее доступное предложение |
| --- | --- | --- |
| Деревья | Новая задача ещё не начата; интересы автора сохранены ниже | Поставить базовую задачу бинарного дерева поиска из СА-03 |
| Графы | Новая задача ещё не начата; интересы автора сохранены ниже | Обсудить первую задачу по представлению графа и обходам из СА-04 |

На запрос «что дальше?» без выбора темы текущая рекомендация — начать
бинарное дерево поиска. Это предложение по умолчанию, а не ограничение
перехода к графам или другой теме. Незавершённых новых задач по деревьям
и графам сейчас нет; полигоны для этих идей ещё не создавались.

Сортировки, графовые задачи и сравнительные исследования из
[спецификации](specification.md#са-01-реализация-и-сравнение-алгоритмов-сортировки)
также доступны для выбора. Нумерация СА сохраняет связь с исходной
адаптацией и не задаёт обязательный порядок занятий.

## Деревья: интересы автора

Следующие направления обсуждены и отмечены автором как интересные
для дальнейшего изучения. Они ещё не являются начатыми задачами.
СА-03 уже предусматривает BST, АВЛ, обходы и рекомендует порядковые
статистики. Таблица сохраняет и эти направления, и обсуждённые дополнения;
дополнения не приписываются учебному пособию.

| Направление | Сохранённые идеи |
| --- | --- |
| Бинарное дерево поиска (BST) | Поиск, вставка, удаление, политика равных ключей, высота и количество элементов; минимум и максимум; предшественник и преемник; ближайший ключ снизу и сверху; выдача элементов диапазона |
| Обходы | Симметричный, прямой, обратный и по уровням; рекурсивные и итеративные варианты там, где они содержательны; применение собственных стеков и очередей |
| Форма дерева и пути | Наименьший общий предок; путь между элементами; диаметр; сравнение формы и высоты при разных входах |
| Построение и восстановление | Построение дерева минимальной высоты из отсортированной последовательности; сериализация и восстановление структуры; восстановление по обходам с обсуждением необходимых данных |
| АВЛ-дерево | Балансировка после вставки и удаления; демонстрация изменений формы; сравнение с BST по высоте, числу сравнений и стоимости операций; диапазонные запросы и соседние ключи |
| Порядковые статистики | Элемент по порядковому номеру; количество элементов меньше ключа; количество элементов диапазона; поддержка дополнительной информации в дереве |
| Декартово дерево (treap) | Сочетание порядка поиска и приоритетов; разделение и объединение деревьев |
| Бор (trie) | Поиск по частям ключа, префиксный поиск и автодополнение |
| Дерево отрезков | Агрегаты по диапазонам, суммы и минимумы; точечные и диапазонные обновления |
| Красно-чёрное дерево | Другой подход к балансировке и сравнение с АВЛ |

Связи между этими идеями можно использовать для выбора следующего шага,
не превращая их в требование закончить все алгоритмы BST до АВЛ или все
разновидности деревьев до графов. Вопросы общей формы дерева могут стать
отдельными алгоритмами; новую универсальную иерархию ради них заранее
не вводить.

## Графы: исходные направления и интересы автора

СА-04…СА-08 уже предлагают представления графов, обходы, остовы, циклы,
кратчайшие пути и сравнение алгоритмов. Эти направления сохраняются
как доступные задачи и не ограничивают дальнейшее углубление.

| Основание | Направления |
| --- | --- |
| Исходная адаптация | Ориентированные и неориентированные, взвешенные и невзвешенные графы; матрица и список смежности; согласование петель, кратных рёбер и несвязности |
| Исходная адаптация | DFS и BFS, порядок посещения, деревья обхода, достижимость и расстояния по числу рёбер; разные способы реализации там, где это имеет смысл |
| Исходная адаптация | Минимальные остовы: Прим и Крускал; эйлеровы и гамильтоновы циклы; кратчайшие пути с выбором алгоритма по условиям задачи и восстановлением маршрута |
| Отмеченный интерес автора, дополнение к адаптации | Потоковые сети, максимальный поток, метод Форда — Фалкерсона; собственное рабочее состояние алгоритма и представление результата |

Если предложенные направления не подходят под настроение, нейросеть
продолжает поиск других задач и связей в этой теме. Новые выбранные автором
точки погружения добавляются сюда без отдельной команды «запиши».

## Сквозные интересы

- Несколько содержательных решений одной задачи: рекурсия и циклы,
  разные представления данных и стратегии. Сравнение результатов,
  сложности, памяти и читаемости; демонстрации и отдельные измерения.
- Разделение структуры и алгоритмов: операции, поддерживающие контракт
  структуры, и самостоятельные задачи на ней. Большой алгоритм может иметь
  собственное рабочее состояние, явные вход и результат; размер метода
  сам по себе не определяет место реализации.
- Доступ алгоритма к структуре без обязательного раскрытия изменяемых
  внутренних узлов. Необходимые средства доступа и общие абстракции
  обсуждать по реальным задачам, без инфраструктуры на будущее.
