# Ревью CircularArrayList<T>

## Функциональная корректность и надёжность

Этап завершён. Исправления реализации и завершение перечислителя выполнены
по явному запросу автора. Insert и RemoveAt поддерживают согласованное положение
конца последовательности. Физическое начало больше не преобразуется повторно
как логический индекс при чтении и очистке. Clear очищает оба занятых участка
кольцевого хранилища, сохраняя вместимость. Пустые First и Last выбрасывают
InvalidOperationException. Рост сохраняет логический порядок; вычисление индексов
и новой вместимости исключает переполнение int.

Перечислитель фиксирует версию при создании и идёт в логическом порядке без копии.
Current и MoveNext обнаруживают изменения до начала, во время, после завершения
и после Dispose. Dispose завершает обход, повторный вызов безопасен;
Reset не поддерживается. Поиск сохраняет контракт IndexedPredicate<T>:
элемент и логическая позиция, первое совпадение, обнаружение изменений,
передача исключений условия, отсутствие защитной проверки ненулевого условия.

## Архитектура, код и API

Отдельный этап завершён. Хранилище — T[], кольцевая организация скрыта,
позиционный API соответствует [профилю](../array-list-profiles.md) и
[словарю](../collection-semantics.md). Стоимость вставки и удаления зависит
от расстояния до ближайшего конца; операции с концами сохраняют требуемые
O(1) и амортизированное O(1). Перечислитель содержит только владельца,
версию и позицию, копии содержимого не создаются. Новых интерфейсов Core нет.

Свойства концов приведены к согласованным именам First и Last.
Исходный класс проверок обычного списка снова называется ArrayListTests.
Семантические переименования вызваны через Rider: каждый затрагивал только
объявление без вызывающих мест. Публичные XML-комментарии оформлены после
обоих этапов и описывают поведение, ошибки, стоимость и инвалидирование обхода.

## Проверки

Общие проверки в Collections/ArrayListContract выполняются для ArrayList<T>
и CircularArrayList<T> через прямые тестовые адаптеры. Проверяются создание,
ошибки индексов без изменения состояния, null и ссылочная идентичность,
перебор через оба интерфейса, вложенные обходы, состояния перечислителя,
изменения, поиск, очистка и повторное использование.
Смешанные последовательности по 3000 операций сверяются с List<int> после
каждого шага для трёх фиксированных seed и начальных вместимостей.

Специфические тесты в Collections/CircularArrayList перебирают малые состояния
для вместимостей 1, 2, 3, 5 и 8: смещения начала, количества элементов
и допустимые позиции вставки и удаления. Проверяются рост, последующее
добавление и чтение концов. Проверки хранилища отдельно подтверждают очистку
ссылок и структур со ссылочными полями при удалении и Clear.
Ранее существовавшие проверки ArrayList сохранены.

Единственный Laboratory-факт демонстрирует переход через конец массива,
рост, позиционные операции, концы, поиск, foreach, ошибки, изменение при обходе,
очистку и повторное использование. Поддерживает новый случайный seed и повтор
через DATASTRUCTURES_LAB_SEED. Прогоны с seed 690022176 и 12345 прошли.

Locked restore, сборка Release без предупреждений, проверка форматирования
и все 450 обычных тестов прошли. Восстановление использует пользовательский
NuGet-кэш; packageFolders обоих проектов проверены.

Rider inspections выполнены для изменённых C#-файлов. Явный Dispose внутри
using сохранён для проверки состояния после освобождения и повторного Dispose;
using обеспечивает освобождение при падении Assert. Подсказки об аллокациях
и boxing ожидаемы в тестах и демонстрации. Предложения вынести локальные
ожидаемые массивы в static readonly, переставить локальные функции и заменить
ветвление на switch оставлены без изменения: данные локальны, функции находятся
перед использованием, ветвление соответствует группам операций. foreach сохранён
как предмет проверки. Делегаты не сохраняются за пределами запуска.
