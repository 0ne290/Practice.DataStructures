# Ревью расширения ArrayList<T>: Insert

## Функциональная корректность и надёжность

Этап завершён. Допустимы позиции от нуля до Count включительно:
вставка в пустой список, перед существующим элементом и в конец.
Порядок остальных элементов сохраняется как при свободном месте, так и при
расширении хранилища. Count увеличивается на один. Недопустимая позиция
отклоняется до изменения содержимого, вместимости и версии.
Успешная вставка инвалидирует перечислители и обнаруживается поиском,
если выполнена из условия. Выделение нового массива предшествует смене хранилища.
Общий механизм расширения используется также Add; его поведение сохранено.

## Архитектура, код и API

Отдельный этап завершён без замечаний к реализации. Имя Insert и поведение
соответствуют согласованному профилю в [профилях списков](../array-list-profiles.md)
и [словаре](../collection-semantics.md). Хранилище остаётся T[],
публичные возможности списка не раскрывают его физическое устройство.
Существующий механизм роста выделен в закрытый EnsureCapacity.
Без расширения вставка стоит O(1 + n − index), с расширением — O(n).
Вставка в конец имеет амортизированную стоимость O(1).

После обоих этапов обновлены XML-комментарии типа и перечисления,
оформлен контракт Insert. Реализация и объявления автора не изменялись.

## Проверки

Добавлены 27 детерминированных проверок в ArrayListInsertionTests:
позиции вставки, порядок и рост, null и сохранение ссылочной идентичности,
недопустимые индексы без изменения состояния, перечислители до начала,
во время, после завершения и после Dispose, изменение из условия поиска.
Смешанные операции сверяются с List<int> после каждого шага для двух seed.
В существующий единственный Laboratory-факт добавлена демонстрация вставок.

Locked restore, сборка Release без предупреждений, проверка форматирования
и все 392 обычных теста прошли. Демонстрация прошла с новым случайным
seed 799725265 и с заданным seed 12345. Восстановление использует пользовательский
NuGet-кэш; packageFolders обоих проектов проверены.

Rider inspections выполнены для всех изменённых C#-файлов.
Явный Dispose внутри using оставлен для проверки состояния после освобождения;
using обеспечивает освобождение при падении проверки. Подсказки об аллокациях,
boxing, замене if на switch и вынесении локального ожидаемого массива в static
readonly оценены: текущие тесты сохраняют локальные данные и не измеряют память.
foreach в демонстрации оставлен как предмет проверки.
Делегаты и их замыкания не сохраняются за пределами запуска.
