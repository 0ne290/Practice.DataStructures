## Точка продолжения

Оба этапа ревью завершены. Все перечисленные ниже замечания исправлены.
Общий базовый класс коллекций и перечислителей решено не вводить.
Чтение оформлено через TryFirst/TryLast/TryFindFirst с bool и out T;
UpdateFirst поддерживает ссылочные T, значимые типы отклоняются до поиска.
Делегаты вызываются напрямую с проверкой версии после нормального завершения.
XML-комментарии и тесты оформлены; единственный Laboratory заменён демонстрацией.
По явному запросу автора прежнее API выделено в `Values`, добавлено отдельное
`Cursors`. Оба объекта доступа используют прежнее хранилище, общий Count и перебор.
Операции над значениями реализованы непосредственно в ValueApi, курсорные операции —
в Cursor. Приватные копии методов ValueApi на самом списке удалены. Общие механизмы
вставки, удаления, замены значения, поиска и проверки версии сосредоточены в списке.
Удаление инвалидирует курсоры и освобождает ссылки узла; очистка сменяет поколение за O(1).
Каждый компонент вынесен в отдельный файл через partial-объявления внешнего типа:
SinglyLinkedList, ValueApi, CursorApi, Cursor, Node и Enumerator. Полные имена
вложенных типов и публичные вызовы сохранены.
Курсор работает вперёд и редактирует после позиции; BeforeFirst позволяет
работать с головой без поиска предшественника. Изменения других элементов
сохраняют курсоры, удаление своего элемента и очистка делают их недействительными.
Выполнены самопроверка корректности смешанных операций и отдельная проверка
разделения API. Прежние проверки перенесены на Values без ослабления утверждений;
добавлены 19 обычных проверок курсоров и расширен прежний Laboratory.
Подсказки Rider о выделениях памяти оставлены как ожидаемые; существующие
циклы в тестах сохранены для проверки вложенного и необобщённого перебора.
Текущий результат: 291 обычный тест, из них 68 проверок односвязного списка.
Restore в locked mode, сборка Release, форматирование, Rider inspections и
демонстрация с новым случайным seed и seed 12345 выполнены успешно.

## Исправленные замечания исходного ревью

- [x] **Перебор непустого списка сразу падает.** `Enumerator.MoveNext`, строка 291:
  первый вызов обращается к `_currentNode!.Next`, хотя `_currentNode` ещё равен
  `null`. Даже `foreach` по списку из одного элемента приводит к
  `NullReferenceException`. Также проверить завершение обхода: достижение хвоста
  сейчас возвращает `false`, а `Current` продолжает выдавать его значение после
  окончания перечисления.

- [x] **AddBefore вставляет после найденного элемента.** Строки 107–108:
  для любого элемента, кроме головы, изменяется `targetNode.Next`.
  Вставка `9` перед `2` в `[1, 2, 3]` создаёт `[1, 2, 9, 3]`.
  При выборе хвоста новый последний узел не становится `_tail`, и последующий
  `AddLast` отсоединяет его от цепочки, сохраняя неверный `Count`.

- [x] **Удаление хвоста падает и повреждает состояние списка.** `_find`, строка 127:
  найденный хвост возвращается с `previousNode = null`. Затем `RemoveFirst`
  присваивает этот `null` полю `_tail` и обращается к `_tail.Next`.
  Воспроизведение: `[1, 2]`, удаление по условию `value == 2`.
  После исключения `Count` остаётся равным `2`, а `_tail` уже потерян.

- [x] **Поиск первого совпадения может выбрать последнее.** `_find`, строка 126:
  хвост проверяется раньше промежуточных узлов. Для `[1, 2, 3]` и условия
  `value >= 2` метод `FindFirst` вернёт `3`, а `PositionOf` — `2`.
  Та же ошибка выбора распространяется на замену, обновление, удаление и вставки
  по условию. При отсутствии совпадений порядок вызовов предиката будет `0, 2, 1`.

- [x] **В одноэлементном списке предикат вызывается дважды для одного элемента.**
  `_find`, строки 124–128: проверка `Count == 1` выполняется после проверок головы
  и хвоста, которые здесь совпадают. Если первый вызов вернул `false`, последует
  повторный вызов с теми же аргументами. Это наблюдаемое поведение для предикатов
  со счётчиком, состоянием или побочными эффектами.
